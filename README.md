# SBT-DF203_Lab7_DNS-Introduction-and-Traffic-Analysis
Network forensics investigation of Domain Name System (DNS) resolution mechanics using dig, TShark, and Wireshark. Includes PCAPNG packet-level analysis of DNS queries/responses (A, AAAA, MX, NS records), transaction ID correlation, TTL cache evaluations, browser-generated query inventories, and Layer 7 to IP connection correlation.
